# 바이탈리티럽 (VitalityRub)

출장마사지·홈타이 방문 안내 정적 사이트. 외부 의존성 없이 Node 20 표준 라이브러리만 쓴다.

## 돌리는 법

```bash
npm run regions   # 행정동 경계 → data/regions.json (원본 geojson 필요)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 16종
npm run simil     # 동 페이지끼리 본문 겹침 측정
npm run serve     # dist/ 를 로컬에서 띄워 보기
```

## 이 사이트가 재는 값 — 누운 방향

땅의 바깥 테두리를 **각도를 바꿔 가며 감싸** 넓이가 가장 작은 네모를 찾고(회전 캘리퍼스),
그 네모의 긴 변이 가리키는 쪽을 22.5도씩 여덟 갈래로 묶어 적는다.

| 값 | 뜻 |
|---|---|
| 누운 결 | 긴 변이 가리키는 쪽(여덟 갈래) |
| 길쭉함 | 긴 변 ÷ 짧은 변 |
| 긴 변·짧은 변 | 감싼 네모의 두 변 길이(m) |
| 채운 몫 | 그 네모를 땅이 채우는 비율(%) |
| 결 짝·결 어긋남 | 같은 시군구에서 각도 차가 가장 작은 칸과 가장 큰 칸 |

★지도를 그대로 놓고 가로세로를 재면 비스듬히 누운 땅이 네모로 읽힌다. 그래서 돌려서 잰다.

## 커버리지

- **동까지** 서울·인천·경기·부산 — 1,232칸
- **시군구까지** 대전·대구·울산 전역 + 광주 광산구 + 지정 시·군
- 읍과 면은 화면을 내지 않고 시군구 목록에 이름만 올린다(접수와 방문은 동일).

## 꼭 지킬 것

- `data/lastmod.json` 을 **반드시 커밋**한다. 없으면 깃 빌드에서 전 쪽이 '오늘 수정'으로 밀린다.
- 전화번호는 `dialBtn()` 으로만 찍는다. 맨 번호가 본문에 남으면 `npm run check` 가 잡는다.
- 무작위를 쓰지 않는다. 모든 변형은 md5 시드 고정이라 같은 주소면 언제나 같은 HTML 이 나온다.
- 후기·체험담·평점·인물 사진을 싣지 않는다.
